# Application C abbreviations

| Term | Meaning |
| --- | --- |
| ADC | Analog-to-digital converter |
| API / ABI | Application programming / binary interface |
| B1–B5 / b4 | Project Buddy subsystem numbers |
| BR / br | Motor bring-up / shared safety foundation |
| CRC | Cyclic redundancy check |
| DTR | USB serial data-terminal-ready signal |
| FIFO | First-in, first-out sensor queue |
| GPIO | General-purpose input/output |
| I2C | Two-wire inter-integrated circuit bus |
| IMU | Inertial measurement unit |
| IRQ / ISR | Interrupt request / service routine |
| LE | Little-endian byte order |
| mg | Milli-g, one thousandth of nominal gravity |
| mm / ms / us | Millimetres / milliseconds / microseconds |
| MQTT | Message Queuing Telemetry Transport |
| NAV / nav | Navigation coordinator |
| ODO / odo | Wheel odometry |
| PWM | Pulse-width modulation |
| Q15 | Signed fractional value scaled by 32768 |
| RB / rb | RTOS barcode adapter |
| RI / ri | RTOS IMU adapter |
| RL / rl | RTOS line adapter |
| RN / rn | RTOS network adapter |
| RTOS | Real-time operating system |
| SDK | Software development kit |
| SMP | Symmetric multiprocessing |
| TCP | Transmission Control Protocol |
| TLM / tlm | Telemetry |
| TTL | Time to live |
| UF2 | USB flashing format used for the RP2040 |
| USB | Universal Serial Bus |
