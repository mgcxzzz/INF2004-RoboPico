This is the drive-capable integration image, not the earlier motors-off network proof.

Hardware drive behavior on the robot has not yet been validated. Motion, line/barcode, coordinator, run-summary and diagnostic panels use received firmware frames only. This image does not provide IMU or obstacle telemetry; no values for those systems are inferred.
