# RoboPico Buddy 1–5 RTOS bundle

Download the [v0.4.3 Buddy 1–5 ZIP](firmware/releases/v0.4.3/robopico-v0.4.3-buddy1-5-bundle.zip) and open `START_HERE.md` after extracting it. The ZIP contains the Pico W UF2, Demo Console v0.2.15, launchers and setup instructions.

Use **Start dashboard.cmd** on Windows or `python3 tools/dashboard/run_dashboard.py` on macOS. The firmware uses the Pico W's saved Wi-Fi settings. See the [setup guide](docs/setup.md) if the network changes.

For firmware-only flashing or a reproducible build, see the [release files and manifest](firmware/releases/v0.4.3/).
