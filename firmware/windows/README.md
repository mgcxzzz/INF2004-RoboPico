# Windows launchers

Use [Start dashboard.cmd](Start%20dashboard.cmd) to start the dashboard and local broker checks. Use [Configure WiFi.cmd](Configure%20WiFi.cmd) when the Pico needs a different network or broker address. See the [setup guide](../../docs/setup.md) for requirements and BOOTSEL steps.

These launchers are for a repository checkout. The [published release ZIP](../releases/v0.4.3/) contains its own launchers and setup guide. Run offline checks using the [test runner](../../testing/README.md#run-the-tests).
